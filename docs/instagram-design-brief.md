# Instagram 友達ダッシュボード デザイン依頼書

> 2026-11-02: いただいたデザイン（`design/instagram/`）を反映済みです。最新の仕様は `docs/instagram-requirements.md` を参照してください。

デザインを画像（モックアップ）で作っていただき、それに合わせて実装します。
この資料は「どの画面に何が必要か」の一覧です。ここにある要素はすべてどこかに配置してください。
見た目・並び・まとめ方（タブ、サイドバー、カード、モーダルなど）は自由に変えて構いません。

## 画像の渡し方

- チャットに画像を添付してください。受け取った画像は `design/instagram/` に保存します。
- ファイル名の目安: `01-login.png`、`02-friends-pc.png`、`02-friends-sp.png` のように「番号-画面名-pc/sp」
  （番号は下の画面番号）。
- PC（幅 1200px 前後）とスマホ（幅 390px 前後）の両方があると確実です。スマホ版が無い画面は、
  PC 版をもとにこちらで縦並びにします。
- 色はカラーコード（例: `#E1306C`）、フォント名、角丸・余白の大きさもあれば書き添えてください。
  無い場合は画像から読み取ります。

## 全画面共通

| 要素 | 内容 |
|---|---|
| タイトル | 「Instagram 友達ダッシュボード」（名前の変更も可） |
| ログイン中の表示 | メールアドレス、ログアウトボタン |
| 画面の切り替え | 友達 / イベント / 取り込み（今はタブ） |
| 読み込み中 | データを読んでいる間の表示 |
| エラー | 保存・読み込みに失敗したときのメッセージ |

## 01. ログイン

- メールアドレス入力欄、「ログインリンクを送る」ボタン
- 送信後: 「〇〇にログイン用のリンクを送りました」という表示
- 失敗時: エラーメッセージ

## 02. 友達

**集計（5つの数字）**
- 友達（合計、フォロワーとフォロー中を重複なしで数えた人数）
- フォロワー / フォロー中 / 相互フォロー / DM したことがある人

**絞り込み・並び替え**
- 検索欄（ユーザー名・メモ）
- 関係: すべて / 相互フォロー / フォロワーのみ / フォロー中のみ / つながりなし
- 並び順: 最終 DM が新しい順 / DM 件数が多い順 / フォローされた日が新しい順 / ユーザー名順
- 「DM したことがある人だけ」のオン/オフ

**一覧（1人分の項目）**
- 選択用チェック
- @ユーザー名（押すと Instagram のプロフィールが開く）
- 関係（相互フォロー など）
- フォローされた日、DM 件数、最終 DM の日付
- 追加されているイベントの数
- メモ（その場で編集できる）
- 人数が多い（数百〜数千人）ので、「さらに表示」かページ送りが必要

**まとめて操作**
- 「〇人中 〇人を選択中」、表示中を全選択、選択解除
- イベントを選んで「選択した人をイベントに追加」
- 出力: 「@ユーザー名をコピー」ボタン、「プロフィールのリンク一覧」（開くと @ユーザー名のリンクが並ぶ）
  - 選択している人がいればその人たち、いなければ絞り込み中の全員が対象

**空のとき**: まだデータがない（取り込みへ案内）

## 03. イベント

**イベント一覧**
- 各イベント: 名前、日付（未定の場合あり）、参加人数
- 「新規作成」ボタン

**イベントの作成・編集フォーム**
- イベント名（必須）、日付、場所、メモ
- 保存 / キャンセル、削除（確認あり）

**選んだイベントの詳細**
- 名前、日付、場所、メモ
- ステータスごとの人数と絞り込み:
  すべて / 候補 / 招待済み / 返事あり / 参加 / 不参加 / 来場（ステータスごとに色分けしたい）

**参加者リスト（1人分の項目）**
- @ユーザー名（プロフィールへのリンク）
- ステータス（6種類から変更）
- DM 件数、最終 DM の日付
- メモ（人数・連絡事項など）
- 「外す」ボタン

**その他**
- ユーザー名で検索して参加者に追加する欄（候補が下に出る）
- 出力: 「@ユーザー名をコピー」「プロフィールのリンク一覧」（絞り込んだステータスの人が対象）
- 空のとき: イベントがまだない / 参加者がまだいない

## 04. 取り込み

- Instagram からデータをダウンロードする手順（3ステップ）
- ZIP ファイルの選択（ドラッグ＆ドロップにしても可）
- 解析中の表示
- 解析結果のプレビュー: 友達合計・フォロワー・フォロー中・相互フォロー・DM スレッド（対応付けできた数 / 全体）
- 対応付けできなかった DM の一覧（折りたたみ）
- 「この内容で保存する」「やめる」ボタン
- 保存完了 / エラーのメッセージ

## 実装側のメモ

画面を作り直してもデータ処理はそのまま使えるよう、次のように分けています。

| ファイル | 役割 |
|---|---|
| `lib/instagram/useInstagram.ts` | ログイン状態とデータ読み込み |
| `lib/instagram/api.ts` | Supabase への保存・更新・削除 |
| `lib/instagram/selectors.ts` | 絞り込み・並び替え・集計、表示用ラベル |
| `lib/instagram/parse.ts` | エクスポート ZIP の解析 |
| `components/instagram/*` | 見た目（デザインに合わせて作り直す部分） |
