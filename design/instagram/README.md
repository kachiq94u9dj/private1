# デザイン画像置き場

Instagram 友達ダッシュボードのデザイン画像（モックアップ）をここに置きます。
必要な画面と要素は [`docs/instagram-design-brief.md`](../../docs/instagram-design-brief.md) を参照してください。

ファイル名の例: `01-login-pc.png`, `02-friends-pc.png`, `02-friends-sp.png`, `03-events-pc.png`, `04-import-pc.png`
